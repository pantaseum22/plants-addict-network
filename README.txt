PLANTS ADDICT NETWORK - 動くサイト試作品

1. index.html をブラウザで開くと動作します。assets フォルダは同じ階層に置いてください。
2. スマホ・PCの画面幅に合わせてレイアウトが変わります。
3. 商品カテゴリー切替・検索・お気に入り・デモカートが動作します。決済・注文機能はありません。
4. 右下の「コンテンツ編集」から文章、商品名、価格、商品画像を変更できます。
   ただし変更は「そのブラウザのlocalStorage」にのみ保存され、ほかの端末・訪問者には反映されません。
   本番の共有更新にはCMS/データベースと管理画面を別途構築する必要があります。
5. 掲載画像はユーザー提供のデザインモックアップから切り出した仮素材です。
   実際の商品写真・正確な価格・正式なロゴ・お問い合わせ先へ差し替えてください。
6. 公開するには、このフォルダを静的ホスティング（Netlify, Cloudflare Pagesなど）にアップロードします。
   この作業はまだ実施していません。
